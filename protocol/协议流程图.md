## 1. AA 协议 TX/RX 一问一答总览

UART 物理层（9600 8N1）承载 **AA 应用层定长帧**：PC 发 **25 B**，芯片回 **17 B**。

```mermaid
flowchart LR
    subgraph PC["PC 上位机 (EVB-COM-TOOL)"]
        A1["CSV / UI 输入<br/>12 路 DAC + Mode"]
        A2["build_tx_frame()<br/>组 25 B TX 帧"]
        A3["parse_rx_frame()<br/>解析 17 B RX 帧"]
        A4["needs_retry()<br/>CH1–8 收敛判定"]
    end

    subgraph UART["UART 9600 8N1"]
        B1["TX 25 字节"]
        B2["RX 17 字节"]
    end

    subgraph CHIP["EVB 通信芯片"]
        C1["接收 AA 帧头 0xAA"]
        C2["内部迭代译码<br/>（迭代次数编码于 RX byte0）"]
        C3["回传 8 路 ADC 读数"]
    end

    A1 --> A2 --> B1 --> C1 --> C2 --> C3 --> B2 --> A3 --> A4
    A4 -->|"未收敛<br/>raw < 0x2FF"| A2
    A4 -->|"已收敛<br/>或达最大重试"| DONE["记录 SendResult<br/>进入 BER / 导出"]
```

| 方向 | 帧长 | 首字节含义 | 载荷 |
|------|------|-----------|------|
| **TX** (PC→芯片) | 25 B | `0xAA` 帧头 | 12 组 × 2 B（12-bit DAC，大端） |
| **RX** (芯片→PC) | 17 B | 迭代次数编码 | 8 组 × 2 B（12-bit ADC，大端） |

> RX 首字节 **不是** `0xAA`；迭代次数 = `byte0 + 1`。

## 2. TX 25 字节帧组帧流程

对应 `codec.build_tx_frame()` / `codec.decode_tx_frame()`。

```mermaid
flowchart TD
    START(["开始：12 路 DAC 码 + Mode"]) --> CHECK{"channels<br/>长度 == 12?"}
    CHECK -->|否| ERR["抛出 ValueError"]
    CHECK -->|是| HDR["frame[0] = 0xAA<br/>（帧头 FRAME_HEADER）"]
    HDR --> LOOP["遍历 i = 0..11"]

    LOOP --> CLAMP["val = clamp12(raw)<br/>限制 0x000 ~ 0xFFF"]
    CLAMP --> MODE{"i == 0 ?<br/>（CH1）"}
    MODE -->|是| M1["mode_nibble = Mode & 0x03<br/>（A1 批量固定 1）"]
    MODE -->|否| M0["mode_nibble = 0<br/>（沿用，不改矩阵模式）"]

    M1 --> PACK
    M0 --> PACK["high = mode_nibble<<4 | val[11:8]<br/>low = val[7:0]<br/>写入 frame[1+2i], frame[2+2i]"]

    PACK --> MORE{"还有下一通道?"}
    MORE -->|是| LOOP
    MORE -->|否| OUT(["输出 25 B TX 帧"])

    style HDR fill:#e8f4fd
    style OUT fill:#d4edda
```

## 3. RX 17 字节帧解析流程

对应 `codec.parse_rx_frame()` / `codec.decode_rx_frame()`。

```mermaid
flowchart TD
    START(["开始：接收 17 B 原始字节"]) --> LEN{"len(data) >= 17?"}
    LEN -->|否| ERR["ValueError<br/>帧长度不足"]
    LEN -->|是| ITER["iteration = byte0 + 1<br/>（芯片迭代次数）"]

    ITER --> LOOP["遍历 i = 0..7（8 路 ADC）"]
    LOOP --> RAW["high = data[1+2i]<br/>low = data[2+2i]<br/>raw = ((high<<8)|low) & 0x0FFF"]
    RAW --> CURR["I_col = raw_to_column_current(raw)<br/>（见 §4）"]
    CURR --> APPEND["outputs[i] = {raw, current, …}"]
    APPEND --> MORE{"还有下一通道?"}
    MORE -->|是| LOOP
    MORE -->|否| CONV["converged = is_recv_valid(raws)<br/>CH1–8 raw 均 ≥ 0x2FF?"]
    CONV --> OUT(["返回 {iteration, outputs, converged}"])

    style ITER fill:#fff3cd
    style CONV fill:#f8d7da
    style OUT fill:#d4edda
```

### RX 帧字节布局

```mermaid
flowchart LR
    subgraph RX17["RX 帧 17 字节"]
        B0["Byte0<br/>迭代次数编码<br/>（实际次数 = byte0+1）"]
        AD1["Byte1–2<br/>CH1: Mode[3:0]+ADC[11:8] | ADC[7:0]"]
        AD2["Byte3–4<br/>CH2 ADC"]
        DOTS["…"]
        AD8["Byte15–16<br/>CH8 ADC"]
    end
    B0 --> AD1 --> AD2 --> DOTS --> AD8
```

> **收敛判定看 CH1–8**（全部 8 路）；任一路 raw < 0x2FF 即触发重发。

## 4. 物理量换算：DAC→V_row / ADC→I_col

对应 `codec.py` 中常量与换算函数。

```mermaid
flowchart TD
    subgraph TX_PATH["发送侧：行电压 (忆阻器阵列)"]
        IN["CSV In[i]<br/>相对 2.5 V 中点偏移"] --> INV["in_value_to_row_voltage()<br/>V_row = 2.5 + In[i]<br/>clamp [0, 4.096] V"]
        INV --> R2R["row_voltage_to_raw()<br/>raw = round(V_row / 4.096 × 4096)"]
        R2R --> DAC["12-bit DAC 码<br/>0x000 ~ 0xFFF"]
        DAC --> VROW["raw_to_row_voltage()<br/>V_row = (raw / 4096) × 4.096"]
    end

    subgraph RX_PATH["接收侧：列电流 (InfoBit 符号比对)"]
        ADC["12-bit ADC raw<br/>0x000 ~ 0xFFF"] --> ICOL["raw_to_column_current()<br/>I_col = ((raw/4096×5) − 2.5) × (−1)"]
        ICOL --> SIGN{"I_col 符号"}
        SIGN -->|"I_col < 0"| BIT1["chip bit = 1"]
        SIGN -->|"I_col ≥ 0"| BIT0["chip bit = 0"]
    end

    style VROW fill:#e8f4fd
    style ICOL fill:#fff3cd
```

### 换算公式速查

| 方向 | 函数 | 公式 | 备注 |
|------|------|------|------|
| TX | `raw_to_row_voltage` | **V_row = (raw / 4096) × 4.096** | 满量程 4.096 V |
| TX | `in_value_to_row_voltage` | V_row = 2.5 + In[i]，clamp [0, 4.096] | CSV 输入映射 |
| RX | `raw_to_column_current` | **I_col = ((raw/4096×5) − 2.5) × (−1)** | raw=2048 → I_col=0 |
| RX | 逆变换 | raw = (2.5 − I_col) / 5 × 4096 | `column_current_to_raw` |

```mermaid
flowchart LR
    RAW2048["raw = 2048<br/>（中点）"] --> ZERO["I_col = 0"]
    RAWLOW["raw < 2048"] --> POS["I_col > 0"]
    RAWHIGH["raw > 2048"] --> NEG["I_col < 0"]
```

## 5. RX 校验与收敛判定

对应 `validator.py`：`validate_rx_frame()` 与 `needs_retry()` 逻辑等价，输入形态不同。

### 5.1 双入口一致性

```mermaid
flowchart TD
    subgraph ENTRY_A["入口 A：字节流（UART 原始帧）"]
        VA["validate_rx_frame(data)"]
        VA --> VA1{"len(data) >= 17?"}
        VA1 -->|否| VAF["返回 (False, '帧长度不足')"]
        VA1 -->|是| VA2["解析 CH1–8 raw<br/>大端 12-bit & 0xFFF"]
        VA2 --> VA3{"任一路 raw < 0x2FF?"}
        VA3 -->|是| VAF2["返回 (False, '通道 x 原始值 < 0x2FF')"]
        VA3 -->|否| VOK["返回 (True, 'OK')"]
    end

    subgraph ENTRY_B["入口 B：已解析 outputs（comm 层）"]
        NB["needs_retry(outputs)"]
        NB --> NB1["遍历 outputs[0..7]<br/>（CONVERGE_CHANNELS=8）"]
        NB1 --> NB2{"任一路 o['raw'] < 0x2FF?"}
        NB2 -->|是| RETRY["返回 True（需重发）"]
        NB2 -->|否| OK["返回 False（已收敛）"]
    end

    VAF2 -.->|"等价"| RETRY
    VOK -.->|"等价"| OK

    style VOK fill:#d4edda
    style OK fill:#d4edda
    style VAF fill:#f8d7da
    style VAF2 fill:#f8d7da
    style RETRY fill:#fff3cd
```

> **一致性：** `needs_retry(outputs) == True` ⟺ 等长帧上 `validate_rx_frame(data)` 返回 `(False, …)`  
> **范围：** CH1–8 全部参与；阈值 `RETRY_THRESHOLD = 0x2FF`（767）。

### 5.2 CH1–8 收敛判定细节

```mermaid
flowchart TD
    START(["收到 RX 帧 / outputs"]) --> CH["取全部 8 路 CH1–8"]
    CH --> EACH{"逐路检查 raw"}

    EACH --> T{"raw >= 0x2FF ?"}
    T -->|否| FAIL["该通道未收敛<br/>标记 low_channels"]
    T -->|是| NEXT{"还有 CH2–8?"}
    NEXT -->|是| EACH
    NEXT -->|否| PASS["全部达标 → 已收敛 ✓"]

    FAIL --> RETRY["上层触发重发同一 TX 帧"]
    PASS --> DONE["success + converged=True<br/>进入 BER / 符号比对"]

    style PASS fill:#d4edda
    style FAIL fill:#f8d7da
    style RETRY fill:#fff3cd
```

### 5.3 codec 层辅助函数关系

```mermaid
flowchart LR
    PARSE["parse_rx_frame()"] --> OUT["outputs 列表"]
    OUT --> NR["needs_retry()<br/>（serial_worker 使用）"]
    OUT --> ISV["is_recv_valid()<br/>（codec 内部）"]
    BYTES["原始 17 B"] --> VR["validate_rx_frame()<br/>（独立字节入口）"]
    NR -.->|"逻辑相同"| ISV
    NR -.->|"逻辑相同"| VR
```

## 6. UART 收发与重试循环（serial_worker）

对应 `comm/serial_worker.py`：QThread 工作线程中的 `_do_send()` 重试逻辑。

### 6.1 线程与命令队列总览

```mermaid
flowchart TD
    UI["主线程 UI"] -->|connect_port / send_frame / send_batch| Q["命令队列 _cmd_queue"]
    Q --> LOOP["run_loop() 工作线程"]
    LOOP --> CMD{"cmd.type"}

    CMD -->|connect| CONN["_do_connect()<br/>打开 COM、清空缓冲"]
    CMD -->|disconnect| DISC["_do_disconnect()"]
    CMD -->|send| SEND["_do_send() → SendResult<br/>emit send_complete"]
    CMD -->|batch| BATCH["_do_batch() 逐组调用 _do_send<br/>emit batch_progress / batch_complete"]
    CMD -->|shutdown| EXIT["退出循环"]

    LOOP --> POLL["_poll_serial()<br/>持续读取 in_waiting → _rx_buffer"]
```

### 6.2 单次发送/接收 + 重试循环

默认 `_max_retries = 5`（不含首次，最多 **6 次 TX**）。

```mermaid
flowchart TD
    START(["_do_send(channels, mode)"]) --> CONN{"串口已连接?"}
    CONN -->|否| E0["SendResult success=False<br/>error='串口未连接'"]
    CONN -->|是| BUILD["frame = build_tx_frame()<br/>retries = 0"]

    BUILD --> LOOP{"retries <= max_retries<br/>（默认 5）?"}
    LOOP -->|否| EUNK["SendResult success=False<br/>error='未知错误'"]
    LOOP -->|是| STOP{"_stop_requested?"}
    STOP -->|是| ESTOP["SendResult error='已停止'"]

    STOP -->|否| TX["清空 _rx_buffer<br/>serial.write(frame)<br/>flush()"]
    TX -->|异常| ETX["SendResult error='发送失败'"]
    TX --> WAIT["deadline = now + timeout_ms<br/>轮询 _poll_serial()"]

    WAIT --> RX{"_read_rx_frame()<br/>凑满 17 B?"}
    RX -->|超时| RT1["retries += 1<br/>重试"]
    RT1 --> LOOP

    RX -->|收到| PARSE["parsed = parse_rx_frame()"]
    PARSE -->|解析失败| RT2["retries += 1<br/>重试"]
    RT2 --> LOOP

    PARSE -->|成功| CONV{"converged =<br/>not needs_retry(outputs)"}
    CONV -->|未收敛| LVR["low_value_retries += 1<br/>retries += 1"]
    LVR --> LCHECK{"retries <= max_retries?"}
    LCHECK -->|是| LOOP
    LCHECK -->|否| PART["SendResult success=True<br/>converged=False<br/>（最后一次 RX 仍计入 BER）"]

    CONV -->|已收敛| OK["SendResult success=True<br/>converged=True"]
    PART --> END(["emit send_complete / 记录 attempts"])
    OK --> END

    style OK fill:#d4edda
    style PART fill:#fff3cd
    style E0 fill:#f8d7da
    style ETX fill:#f8d7da
```

### 6.3 重试触发条件汇总

```mermaid
flowchart TD
    ATTEMPT["每次 TX 尝试"] --> R1{"接收超时?"}
    R1 -->|是| RETRY["retries++，重发同一 TX"]
    R1 -->|否| R2{"parse_rx_frame 失败?"}
    R2 -->|是| RETRY
    R2 -->|否| R3{"needs_retry(outputs)?<br/>CH1–8 任一路 raw < 0x2FF"}
    R3 -->|是| LVR["low_value_retries++<br/>retries++，重发同一 TX"]
    R3 -->|否| SUCCESS["收敛成功，返回 SendResult"]

    RETRY --> LIMIT{"retries > max_retries?"}
    LVR --> LIMIT
    LIMIT -->|是，超时/解析错| FAIL["success=False"]
    LIMIT -->|是，仅未收敛| PARTIAL["success=True, converged=False"]
    LIMIT -->|否| ATTEMPT

    style SUCCESS fill:#d4edda
    style PARTIAL fill:#fff3cd
    style FAIL fill:#f8d7da
```

### 6.4 SendResult 字段说明

| 字段 | 含义 |
|------|------|
| `success` | 是否收到有效 17 B RX（最后一次尝试为准） |
| `converged` | 最后一次 RX 的 CH1–8 是否均 ≥ 0x2FF |
| `retries` | 总重试次数（含超时、解析失败、未收敛） |
| `low_value_retries` | 仅因 raw < 0x2FF 触发的重试次数 |
| `attempts` | 每次有效 RX 快照（含未收敛中间帧，供多行实测导出） |
