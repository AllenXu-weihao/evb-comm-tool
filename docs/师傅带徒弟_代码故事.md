# 师傅带徒弟：这份代码在讲什么故事

> 一位资深软件工程师，对着学生把仓库掰开讲。  
> 目标：**每个文件对应什么需求、用了什么技术、为什么这样写**——通俗到能出书、能画成漫画分镜。

对照仓库：`evb-comm-tool`。想看严谨流程图 → [软件工程视角与VibeCoding重建实验.md](软件工程视角与VibeCoding重建实验.md)。

## 开场白（给学生的一句话）

实验室有一块芯片评估板（EVB）。MATLAB 已经算好「理想答案」。  
你的软件要做的事只有三句：

1. **把理想激励发给芯片**（串口发 25 字节）  
2. **把芯片回传收回来**（收 17 字节；不行就重发）  
3. **和理想答案比一比，算误码，导出三份表**

界面只是遥控器。真正难的是：**别把「没通信好」和「译码错了」混成一锅粥。**

## 漫画总览：一条流水线

把整仓想成一条工厂流水线：

```text
  [CSV 试卷] → [翻译成电信号] → [快递小哥串口] → [收货验货]
       ↑                                              ↓
  [三份成绩单] ← [判卷老师] ← [记每次尝试的作业本]
```

| 分镜 | 角色 | 仓库里是谁 |
|------|------|------------|
| ① 试卷 | 出题老师 | `data/测试集/*.csv` + `csv_loader.py` |
| ② 翻译 | 物理/协议翻译官 | `protocol/codec.py` |
| ③ 验货章 | 「够不够格收货」 | `protocol/validator.py` |
| ④ 快递 | 不堵前台的送货员 | `comm/serial_worker.py` |
| ⑤ 作业本 | 每次尝试记一行 | `analysis/aggregate.py` |
| ⑥ 判卷 | 对不对、错几 bit | `analysis/sign_compare.py` |
| ⑦ 成绩单 | 全班 / 及格 / 错题本 | `report_export.py` + 导出 |
| ⑧ 前台 | 按钮和曲线 | `ui/*` + `main.py` |

## 技术栈一览（你手里有哪些工具）

| 工具 | 干什么 | 像什么 |
|------|--------|--------|
| **Python 3** | 整仓语言 | 通用胶水 |
| **PyQt6** | 窗口、按钮、表格 | 遥控器外壳 |
| **QThread** | 串口别卡死界面 | 后台工人 |
| **pyserial** | 真正读写 COM 口 | 电话线 |
| **matplotlib** | BER 曲线 | 成绩折线图 |
| **openpyxl** | 写出带颜色的 Excel | 荧光笔成绩单 |
| **csv / dataclass** | 试卷与内存对象 | 表格 ↔ 卡片 |

没有微服务，没有数据库。这是**实验室仪器软件**：小而准，规则写死。

## 逐文件：需求 → 技术 → 人话

### `main.py` — 开机键

| | |
|--|--|
| **需求** | 双击就能打开窗口 |
| **技术** | PyQt `QApplication` |
| **人话** | 只负责「把灯打开」，业务别往这里堆。 |

---

### `protocol/codec.py` — 翻译官

| | |
|--|--|
| **需求** | PC 数字 ↔ 芯片认识的 25B/17B；电压公式别算错 |
| **技术** | 纯函数、字节拼装、大端 12-bit |
| **人话** | 「2.5 伏特」芯片听不懂，要译成 DAC 码；回来的 raw 要译成 `Out`。  
| **漫画** | 海关翻译：护照（浮点）↔ 签证章（字节）。 |

关键口诀：`Out ≈ 2.5` 多半是 raw≈0 → **还没收好货**，不是翻译官算错。

---

### `protocol/validator.py` — 验货章

| | |
|--|--|
| **需求** | 回传够不够「硬件收敛」；不够就让快递重送 |
| **技术** | 阈值常量 `0x2FF`；检查 8 路 raw |
| **人话** | 八个箱子都要盖到章。差一个 → 整单重发。  
| **漫画** | 仓库门卫：章盖齐才放行。 |

记住：**盖章 ≠ 答案正确**。盖章只说明「信号像样了」；对不对是判卷老师的事。

---

### `comm/serial_worker.py` — 快递小哥（后台）

| | |
|--|--|
| **需求** | 连 COM、发帧、收帧、超时/未收敛重试；批量 7000 帧时界面还能点「停止」 |
| **技术** | `QThread` + `pyserial`；每次 RX 记一条 `RxAttempt` |
| **人话** | 前台不能自己跑腿，否则窗口假死。小哥在后院跑，跑完喊一声。  
| **漫画** | 前台小姐姐点单 → 后厨小哥颠勺 → 铃铛一响上菜。 |

---

### `csv_loader.py` — 试卷管理员

| | |
|--|--|
| **需求** | 读入仿真 CSV；内存里变成「仿真行 + 实测行」；导出时按口径筛行 |
| **技术** | CSV DictReader/Writer；双行交错；`build_export_rows` |
| **人话** | 左边是标准答案（仿真），右边是学生卷子（实测）。重发多次就多贴几张草稿纸（Attempt）。  
| **漫画** | 文件夹：每题两页纸；不及格重做再夹一页。 |

导出三份成绩单的「筛法」也在这里定调（和 `report_export` 搭档）。

---

### `analysis/aggregate.py` — 作业本

| | |
|--|--|
| **需求** | 一次收发结果变成可统计的 `CaseRecord`；多次 Attempt 不丢 |
| **技术** | `@dataclass`；`fill_measured` |
| **人话** | 把快递回执贴进档案袋：第几次、收了啥、收敛没、比对比过没。 |

---

### `analysis/sign_compare.py` — 判卷老师

| | |
|--|--|
| **需求** | 按 Mode1/2/3 规定的通道，比实测 CodeBit 和仿真 CodeBit，算 BER |
| **技术** | 符号硬判；按模式选下标 |
| **人话** | Mode1 改前四题；Mode2 改某四道特殊题；Mode3 只改两题。别改错题号。  
| **漫画** | 三种试卷模板，红笔只圈指定格子。 |

---

### `analysis/report_export.py` — 错题本打印机

| | |
|--|--|
| **需求** | 从「已及格卷」里只抽出答错的题，并把错格涂粉红 |
| **技术** | openpyxl 单元格填充；`filter_ber_error_rows` |
| **人话** | 不是再考一次，是把错题剪下来订成册，方便开会怼硬件。 |

---

### `analysis/dataset_accuracy.py` — 防作弊抽检

| | |
|--|--|
| **需求** | 仿真行标准答案不许被管道偷偷改掉 |
| **技术** | 加载时快照；导出时逐格比对 |
| **人话** | 出题纸被复印机「优化」过，成绩就全废。抽检就是防复印机手贱。  
| **漫画** | 封条：标准答案袋，未授权勿拆。 |

---

### `ui/main_window.py` — 前台总机

| | |
|--|--|

## 三份 Excel：用成绩单比喻

| 文件 | 比喻 | 里面有啥 |
|------|------|----------|
| **result** | 全程监控录像 | 每一次重做、每一次 2.5，全留着 |
| **ok** | 及格名单 | 最终仍不及格的**整题撕掉**（题干+所有草稿纸）；及格的只留最后成功那页 |
| **ber** | 错题本 | 只从及格卷里挑「答案和标准不一致」的题，红笔标错格 |

学生常踩的坑：

> 「ok 里怎么还有 2.5？」  
> → 那是旧逻辑或旧文件。新逻辑里，2.5 只该出现在 result 的「重做页」。

## 三条师傅叮嘱（可当书脊金句）

1. **先分清三种失败**  
   没盖章（未收敛）≠ 盖了章但答错（误码）≠ 重做五次仍没盖章（通信失败整题作废）。

2. **标准答案袋上要贴封条**  
   任何「自动补全 / 展开 / 硬判」都可能污染仿真 CodeBit。能空着就空着（`only_empty`）。

3. **慢的事别站在前台做**  
   串口、大表、Excel、扫 7000 行算曲线 → 后台工人。前台只负责微笑和进度条。

## 一页纸速查（贴显示器旁边）

| 你想改的行为 | 先打开 |
|--------------|--------|
| 电压/组帧算错 | `protocol/codec.py` |
| 重发次数/阈值 | `protocol/validator.py` + `serial_worker.py` |
| 导出 ok/ber 规则 | `csv_loader.build_export_rows` + `filter_ber_error_rows` |
| Mode 比哪几路 | `sign_compare.ber_out_indices_for_mode` |
| 界面卡顿 | `perf_settings` / `run_lite.bat` / 别在 UI 线程算表 |
| 仿真 CodeBit 被改 | `dataset_accuracy` + 展开是否 `only_empty` |
